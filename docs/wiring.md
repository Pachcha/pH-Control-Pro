# การต่อสาย — pH Control Pro

บอร์ด: **ESP32 DevKit v1** (30 หรือ 38 ขา)

## ตารางขา

| ขา ESP32 | ต่อกับ | หมายเหตุ |
|---|---|---|
| **GPIO 36** (VP) | สัญญาณ AO ของโมดูล pH | ADC1_CH0 — ขานี้เป็น input only ต่อ output ไม่ได้ |
| **GPIO 4** | ขา DATA ของ DS18B20 | ต้องมีตัวต้านทาน pull-up **4.7 kΩ** ระหว่าง DATA กับ 3.3V |
| **GPIO 0** | ปุ่ม BOOT บนบอร์ด | ไม่ต้องต่อเพิ่ม ใช้ปุ่มที่ติดมากับบอร์ดได้เลย |
| **GPIO 26** | IN1 ของโมดูลรีเลย์ → ปั๊ม **pH Up** | active LOW |
| **GPIO 27** | IN2 ของโมดูลรีเลย์ → ปั๊ม **pH Down** | active LOW |
| **GPIO 14** | IN3 ของโมดูล → **เครื่องกวน** | ย้ายมาจากขา 16 ที่ไม่ตอบสนอง · มีพัลส์สั้นตอนบูต |
| **GPIO 21** | SDA ของจอ LCD I2C | ที่อยู่ I2C 0x27 |
| **GPIO 22** | SCL ของจอ LCD I2C | |
| **5V / VIN** | ไฟเลี้ยง LCD และโมดูลรีเลย์ | |
| **3.3V** | ไฟเลี้ยงโมดูล pH และ DS18B20 | |
| **GND** | กราวด์ร่วมทุกอุปกรณ์ | **ต้องต่อกราวด์ร่วมกันให้หมด** ไม่งั้นค่าที่อ่านได้จะเพี้ยน |

## ขาที่ว่างลง (เดิมใช้กับ EC / ปุ๋ย)

โปรเจกต์นี้ตัด EC และปุ๋ย A-B ออกแล้ว ขาเหล่านี้จึงว่าง เอาไปใช้อย่างอื่นได้

- GPIO 16 — เดิมเป็นเครื่องกวน แต่**ไม่ตอบสนอง** จึงย้ายไปขา 14 แทน
- GPIO 15 — เดิมเป็นรีเลย์ปุ๋ย B
- GPIO 34 — เดิมเป็นเซนเซอร์ EC
- GPIO 25 / 32 / 33 — ว่าง และไม่มีพัลส์ตอนบูต เหมาะกับโหลดที่ไม่อยากให้กระตุก

## ข้อควรระวัง

1. **แยกไฟเลี้ยง** — ปั๊มจ่ายสารกินกระแสสูง ห้ามดึงไฟจากขา 5V ของ ESP32 ให้ใช้อะแดปเตอร์แยกแล้วต่อกราวด์ร่วม ไม่งั้น ESP32 จะรีบูตเองตอนปั๊มทำงาน (brownout)

2. **โมดูล pH ต้องใช้ไฟ 3.3V** — ถ้าจ่าย 5V สัญญาณ AO อาจเกิน 3.3V แล้วขา ADC ของ ESP32 พัง ถ้าโมดูลบังคับใช้ 5V ต้องมีวงจรแบ่งแรงดันคั่น

3. **ADC ของ ESP32 ไม่เป็นเชิงเส้น** — จึงต้อง calibrate 3 จุดเสมอ อย่าใช้สูตรสำเร็จ

4. **วางสาย pH ให้ห่างจากสายไฟ AC และสายปั๊ม** — สัญญาณ pH เป็นอิมพีแดนซ์สูงมาก ถูกรบกวนง่าย

5. **รีเลย์ active LOW** — ตอนบูต ESP32 ขา GPIO จะลอยชั่วครู่ อาจทำให้รีเลย์กระตุกหนึ่งครั้ง ถ้าไม่อยากให้เกิดเลยควรใช้โมดูลรีเลย์แบบ opto-isolated ที่มี pull-up ในตัว

# เปลี่ยนจากรีเลย์เป็นโมดูล MOSFET

โมดูล MOSFET ถูกกว่า เงียบกว่า ไม่มีหน้าสัมผัสให้สึก และถ้าเป็นรุ่นที่มีออปโตคัปเปลอร์
จะแยกกราวด์ฝั่งโหลดออกจาก ESP32 ด้วย — **ช่วยลดสัญญาณรบกวนที่กวนการอ่าน pH ได้มาก**

## ⚠️ ต้องตั้งขั้วสัญญาณให้ถูกก่อนต่อปั๊ม

| ชนิดโมดูล | ขั้วสัญญาณ | ค่าที่ต้องตั้ง |
|---|---|---|
| รีเลย์ทั่วไป | active **LOW** (จ่าย 0V = ทำงาน) | `1` |
| MOSFET ส่วนใหญ่ | active **HIGH** (จ่าย 3.3V = ทำงาน) | `0` |
| MOSFET ที่มีออปโต | **แล้วแต่รุ่น** ต้องทดสอบ | ทดสอบก่อน |

แก้ที่หัวไฟล์ `firmware/pH_Control_Pro/pH_Control_Pro.ino`:

```cpp
#define PH_UP_ACTIVE_LOW    0     // 1 = รีเลย์ , 0 = MOSFET active HIGH
#define PH_DOWN_ACTIVE_LOW  0
#define MIXER_ACTIVE_LOW    0
```

> **ค่าปัจจุบันในโปรเจกต์ตั้งเป็น `0` (MOSFET) แล้ว**
> ถ้าจะกลับไปใช้รีเลย์ ต้องเปลี่ยนกลับเป็น `1` **ก่อน**แฟลช

ตั้งแยกทีละช่องได้ ถ้าผสมรีเลย์กับ MOSFET ก็ยังใช้งานได้

> 🔴 **ตั้งผิดแล้วอันตราย** — ตอนบูตโค้ดสั่ง "ปิด" แต่โมดูลเข้าใจว่า "เปิด"
> ปั๊มจ่ายสารเคมีจะทำงานค้างตั้งแต่เสียบไฟและหยุดไม่ได้จนกว่าจะดึงปลั๊ก

## วิธีทดสอบขั้วอย่างปลอดภัย

**ก่อนอื่น: ถอดสายยางออกจากขวดสารเคมี** ให้ปลายสายจุ่มในน้ำเปล่าหรือปล่อยลอยไว้
ถึงปั๊มจะทำงานผิดจังหวะก็แค่ดูดอากาศ ไม่มีอะไรลงถัง

1. ต่อสายสัญญาณ + กราวด์ + ไฟเลี้ยงโหลด แต่**ยังไม่ต้องต่อปั๊ม**
2. จ่ายไฟ ESP32 แล้วดูไฟ LED ประจำช่องบนโมดูล
   - ถ้า **LED ติดตั้งแต่บูต** → ตั้งขั้วผิด ให้สลับค่า `ACTIVE_LOW` ของช่องนั้น
   - ถ้า **LED ดับ** → ถูกแล้ว
3. เปิดหน้าเว็บ กดปุ่ม **▲ จ่าย pH Up** → LED ช่องนั้นต้องติด แล้วดับเองเมื่อครบเวลา
4. ทำซ้ำกับ pH Down และเครื่องกวน
5. ผ่านครบทุกช่องแล้วค่อยต่อปั๊มและเสียบสายยางกลับเข้าขวด

ถ้าโมดูลไม่มี LED ประจำช่อง ให้ใช้มัลติมิเตอร์วัดแรงดันคร่อมขั้วเอาต์พุตของช่องนั้นแทน
หรือต่อหลอด LED เล็กๆ พร้อมตัวต้านทานเป็นโหลดทดสอบ

## ⚡ ต้องมีไดโอดกันไฟย้อน (flyback diode)

ปั๊มกับมอเตอร์กวนเป็นโหลดเหนี่ยวนำ ตอนตัดไฟจะเกิดแรงดันสวนกลับสูงมาก
ซึ่งทั้งทำให้ MOSFET พังและปล่อยสัญญาณรบกวนไปกวนการอ่าน pH

ต่อไดโอด **1N5822** (หรือ 1N4007) คร่อมขั้วมอเตอร์ทุกตัว:

```
        ┌────────┤◄├────────┐      ← แถบคาดที่ตัวไดโอดอยู่ฝั่ง +
        │                   │
   ปั๊ม (+) ──────────── ปั๊ม (−)
```

**แถบคาดสีอยู่ฝั่งขั้วบวก** ต่อกลับด้านจะลัดวงจรทันที

โมดูล MOSFET บางรุ่นมีไดโอดมาให้ในตัวแล้ว ถ้าไม่แน่ใจใส่เพิ่มก็ไม่เสียหาย

## แยกไฟเลี้ยง

ยังต้องแยกไฟเลี้ยงปั๊มออกจาก ESP32 เหมือนเดิม ต่อ **GND ร่วมกันเฉพาะฝั่งสัญญาณ**
ถ้าโมดูลเป็นแบบออปโต **ห้ามต่อกราวด์สองฝั่งเข้าด้วยกัน** ไม่งั้นจะเสียประโยชน์ของการแยกกราวด์ไปเลย
